# Cipher

> Terse, technical, dark-first. The terminal as design language.

A visual identity in the lineage of modern engineering tooling — Linear, Vercel, GitHub's dark theme, JetBrains, Raycast. Cipher treats the screen like an IDE: dense information, monospace accents, syntax-highlighting palette, dark-by-default. It's for products where users measure quality in milliseconds.

## Design direction

| Aspect | Direction |
|---|---|
| **Mood** | Technical, terse, dense, engineered |
| **Typography** | Inter for UI, JetBrains Mono for accents and code |
| **Color** | Dark-first; gh-dark-style palette with syntax-highlighting accents |
| **Corners** | 6px — the dev-tool default |
| **Density** | Tight; engineers want information density |
| **Voice** | Terse, technical, no fluff. Status codes, exit codes, timestamps. |

## Adobe Fonts (placeholder)

Recommended Typekit families: **Inter** (UI), **JetBrains Mono** / **Iosevka** / **Berkeley Mono** (mono).

## Use this variant for

Developer tools, CI/CD UIs, monitoring dashboards, terminal-adjacent products, internal engineering tools, anything where milliseconds and uptime matter.
