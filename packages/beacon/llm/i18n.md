# Beacon — i18n & RTL Guide

## Recommended locales

| Locale | Status | Notes |
|---|---|---|
| `en` | First-class | Native target |
| `nl` | First-class | Schiphol's home — fitness verified |
| `de`, `fr`, `es` | First-class | — |
| `ja`, `zh` | Tested | CJK pictographic icons pair well |
| `ar` | Tested | Frutiger Arabic recommended |

## Font fallback stacks

```
CJK:        'Noto Sans JP', 'Hiragino Sans', sans-serif
Arabic:     'Frutiger Arabic', 'Noto Sans Arabic', sans-serif
Cyrillic:   'Inter', system-ui, sans-serif
```

## RTL stance

**Supported.** Wayfinding works in any direction.

What changes:
- Layout flips
- Directional arrows mirror
- Breadcrumb separators (›) reverse direction (‹)

What doesn't:
- Numerals and time/flight indicators (use locale numerals where appropriate, but right-justify the column either way)

## Layout gotchas

- **Long localized words** — German "Voreinstellungen" is wider than "Settings". Reserve 30%+ extra width.
- **Times and dates** — present in user's locale format, but always with explicit timezone

## For LLMs

1. Always present the directional arrow alongside CTAs (and mirror in RTL)
2. Use logical CSS properties
3. Don't translate breadcrumb separators with the body text — they're typographic
