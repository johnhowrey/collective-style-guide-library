# Beacon

> Wayfinding clarity. Signage yellow. Hierarchy as design.

Inspired by Paul Mijksenaar's wayfinding work at Schiphol airport. Beacon treats the interface like a sign system: every screen orients before it informs. Strong yellow signal, near-black ink, high-contrast hierarchy, no decoration.

## Design direction

| Aspect | Direction |
|---|---|
| **Mood** | Instructive, oriented, signal-clear |
| **Typography** | Frutiger-lineage humanist sans (Frutiger, Frutiger Next, Vialog) |
| **Color** | White paper, near-black ink, signage yellow `#FFCC00` for primary signal |
| **Corners** | Sharp (0 radius) — signs don't have rounded corners |
| **Density** | Medium; airport-sign whitespace |
| **Voice** | Clear, instructive, hierarchical. "Departures →" |

## Adobe Fonts (placeholder)

Recommended Typekit families: **Frutiger Next**, **Vialog**, **Apex Sans**, **Source Sans 3**.

## Use this variant for

Nav-heavy products, ops dashboards with deep hierarchies, transit / logistics UX, anything where users must orient before they act.
