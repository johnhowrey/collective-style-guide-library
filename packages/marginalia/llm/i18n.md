# Marginalia — i18n & RTL Guide

## Recommended locales

| Locale | Status | Notes |
|---|---|---|
| `en` | First-class | Native target |
| `fr`, `es`, `it`, `de` | First-class | Serif body handles diacritics gracefully |
| `ja`, `zh` | Tested | Pair with Mincho/Song serif fallbacks |
| `ar` | Tested | Naskh Arabic for serif sympathy |

## Font fallback stacks

```
CJK:        'Noto Serif JP', 'YuMincho', 'Hiragino Mincho ProN', serif
Arabic:     'Adobe Arabic', 'Noto Naskh Arabic', serif
Cyrillic:   'PT Serif', Georgia, serif
```

## RTL stance

**Supported.** Bookish typography reads in any direction. Naskh Arabic pairs well with Bembo's classical proportions.

What changes:
- Layout flips
- Page-turn animations reverse direction (forward = leftward in RTL)

What doesn't:
- Brand orange usage and tri-band layouts (those are visual constants)

## Layout gotchas

- **Long French/German hyphenation.** Enable `hyphens: auto` for long-form serif body
- **Vertical Japanese (`writing-mode: vertical-rl`)** is NOT supported in Marginalia — it requires a different metric framework

## For LLMs

1. Maintain serif body family in all locales where possible
2. Use logical CSS properties for layout
3. Reverse page-turn motion direction in RTL
