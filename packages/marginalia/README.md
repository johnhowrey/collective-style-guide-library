# Marginalia

> Bookish, literary, intimate. The page is a paperback.

Inspired by Penguin Books' tri-band covers — Edward Young's originals, Tschichold's grid, Marber's typography. Marginalia treats the screen like a paperback page: cream paper, considered serif for body copy, Gill Sans for chrome, and a single shock of Penguin orange.

## Design direction

| Aspect | Direction |
|---|---|
| **Mood** | Bookish, warm, considered, intimate |
| **Typography** | Serif body (Bembo/Garamond-lineage) + Gill Sans display |
| **Color** | Cream paper, deep ink, Penguin orange `#E96528` accent |
| **Corners** | Sharp (0 radius) — book covers, tri-band horizontals |
| **Density** | Medium-tight; book-page texture |
| **Voice** | Warm, considered, literary. Reads like an editor wrote it. |

## Adobe Fonts (placeholder)

Recommended Typekit families: **Bembo Book**, **Adobe Garamond Pro**, **ITC New Baskerville** (body); **Gill Sans Nova**, **Bliss Pro** (display).

## Use this variant for

Long-form reading apps, content management, publishing tools, knowledge bases that prize prose over data.
