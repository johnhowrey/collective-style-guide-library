# Caesura — i18n & RTL Guide

## Recommended locales

| Locale | Status | Notes |
|---|---|---|
| `en` | First-class | Native target |
| `fr`, `es`, `it`, `de` | First-class | Old-style serif handles diacritics gracefully |
| `ja` | Tested | Pair with Mincho serif |
| `ar` | Tested | Naskh Arabic for serif sympathy |

## Font fallback stacks

```
CJK:        'Noto Serif JP', 'YuMincho', 'Hiragino Mincho ProN', serif
Arabic:     'Adobe Naskh', 'Noto Naskh Arabic', serif
Cyrillic:   'PT Serif', Georgia, serif
```

## RTL stance

**Supported.** Caesura's emphasis on careful spacing and hanging punctuation translates to RTL with care. Naskh Arabic provides classical proportions that fit Caesura's character.

What changes:
- Layout flips
- Hanging punctuation hangs into the *opposite* margin

What doesn't:
- Drop caps (they remain leading-aligned regardless of direction)
- Optical alignment principles

## Layout gotchas

- **Hyphenation.** Enable `hyphens: auto` for justified body in long-form contexts
- **Optical alignment** requires careful handling per script — consult a typesetter if shipping serious editorial in RTL

## For LLMs

1. Maintain serif body family across locales where possible
2. Use logical CSS properties for layout
3. Hanging punctuation should be enabled but its margin direction adapts to writing direction
