# Caesura

> Classical book typography. Careful spacing. The pause before the line resumes.

Inspired by Robert Bringhurst's *The Elements of Typographic Style* — old-style serifs set with care, optical alignment, hanging punctuation, classical proportions. Caesura is what fine typography looks like applied to digital interfaces. Where Marginalia is a paperback, Caesura is a hardcover.

## Design direction

| Aspect | Direction |
|---|---|
| **Mood** | Considered, contemplative, refined |
| **Typography** | Old-style serif (Minion / Caslon-lineage) body; Myriad-lineage sans for UI chrome |
| **Color** | Refined warm cream, considered grays, oxblood `#6B1F1F` accent |
| **Corners** | Sharp (0 radius). Book typography is square. |
| **Density** | Generous; classical book proportions |
| **Voice** | Literary, careful, considered. Reads like Bringhurst himself. |

## Adobe Fonts (placeholder)

Recommended Typekit families: **Minion 3 Pro**, **Adobe Caslon Pro**, **Garamond Premier Pro** (body); **Myriad Pro**, **Adobe Clean** (UI).
