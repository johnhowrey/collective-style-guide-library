# Vellum

> Swiss grid, restrained palette, paper-cool clarity.

A visual identity in the lineage of mid-century Swiss design — Müller-Brockmann, Hofmann, the Basel and Zurich schools. Vellum is what International Style looks like when it grows up into an enterprise SaaS product: precise, calm, undecorated, and entirely committed to the grid.

## Design direction

| Aspect | Direction |
|---|---|
| **Mood** | Calm, precise, paper-cool, unhurried |
| **Typography** | Helvetica-lineage neogrotesque (Neue Haas Grotesk Text/Display) |
| **Color** | Cream paper, charcoal ink, single warm accent (terracotta) |
| **Corners** | 2px subtle radius — softens just enough |
| **Density** | Generous; whitespace is structural |
| **Voice** | Precise, factual, neutral. Confidence through restraint. |

## Adobe Fonts (placeholder)

Documentation systems, knowledge bases, calm enterprise products, anything that wants to feel timeless and uncluttered.
