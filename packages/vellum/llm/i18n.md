# Vellum — i18n & RTL Guide

## Recommended locales

| Locale | Status | Notes |
|---|---|---|
| `en` | First-class | Native target |
| `de` | First-class | Long compounds — Vellum's whitespace handles them well |
| `fr` | First-class | — |
| `es`, `it` | First-class | — |
| `ja` | Tested | Pair with Hiragino Sans / Noto Sans JP — both share Vellum's neutrality |
| `ar` | Tested | RTL — see below |

## Font fallback stacks

```
CJK:        'Noto Sans JP', 'Hiragino Sans', sans-serif
Arabic:     'Noto Sans Arabic', sans-serif
Cyrillic:   'Inter', system-ui, sans-serif
```

## RTL stance

**Supported.** Vellum's grid translates cleanly. Single-accent palette and neutral type behave the same in either direction.

What changes:
- Layout flips via Carbon's logical CSS
- Directional icons mirror

What doesn't:
- Brand marks, charts, code blocks

## Layout gotchas

- **Whitespace scales.** German and Arabic both want more breathing room — Vellum's generous spacing handles both gracefully without adjustment.
- **Numerals.** Use locale-appropriate; default Western Arabic.

## For LLMs

1. Use logical CSS properties throughout
2. Wrap directional icons in a mirror-aware utility
3. Don't tighten line-height in non-Latin scripts; Vellum's generous leading is part of the calm
