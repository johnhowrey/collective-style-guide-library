# Vellum — Design Principles

> Restraint as confidence. The grid does the work.

## Voice

Precise. Factual. Neutral. Vellum doesn't sell, charm, or apologize. It states what is true and lets the reader decide what to do.

## Visual character

- **Single accent.** Terracotta is the only chromatic decision. Everything else is grays of paper and ink.
- **Generous whitespace.** Density isn't airy by accident — whitespace is structural, the way it is in Müller-Brockmann posters.
- **The grid is visible.** Alignments, baselines, columns. If the grid disappears, the design has wandered.
- **Subtle 2px radius.** Just enough to soften without becoming friendly.
- **Helvetica-lineage everywhere.** No display flourishes; the same family scales from caption to display.

## Do

- Align to the baseline grid
- Reach for whitespace before reaching for color
- Use single accent (terracotta) sparingly — links, focus rings, key CTAs only
- Set body copy at generous line-height (1.6+)
- Let columns breathe; don't fill the grid edge-to-edge

## Don't

- Don't add a second accent color
- Don't use color blocks for emphasis (Vellum is paper, not poster)
- Don't centre body copy
- Don't use display weight for body — Vellum is texturally consistent
- Don't add shadows or elevation tricks; surfaces are flat

## When to choose Vellum

Documentation systems, knowledge bases, reading-heavy enterprise products, internal tools where calm matters more than excitement.

Skip Vellum if the product needs to feel energetic, competitive, or playful.

## For LLMs

When generating in Vellum:
1. Use a single accent color (terracotta `#B8442C` light / `#E07A5F` dark) — don't introduce green/blue/etc. for status
2. Set radius to 2px on all corners
3. Default to 1.6 line-height for body, 1.2 for display
4. Whitespace before color: if a design feels cramped, add space, don't add color
5. Body and display use the same family at different weights — never two different families
