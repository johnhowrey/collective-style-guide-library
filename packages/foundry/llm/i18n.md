# Foundry — i18n & RTL Guide

## Recommended locales

Tested character coverage and visual fitness:

| Locale | Status | Notes |
|---|---|---|
| `en` | First-class | Native target |
| `de` | First-class | Long compounds — leave generous trailing space in buttons/headers |
| `fr` | First-class | Watch for accent ascenders in display weight; tighten line-height by 1px if needed |
| `es` | First-class | — |
| `ja` | Tested | Display weight reads heavy; prefer `medium` for h1s. CJK fallback stack required. |
| `ar` | Tested | RTL — see below |

Other locales work via system-font fallbacks but haven't been visually tuned.

## Font fallback stacks

Foundry's primary stack is Latin-only. For non-Latin scripts the foundation auto-applies these via the `lang` attribute:

```
CJK:        'Noto Sans JP', 'Noto Sans SC', 'Hiragino Sans', sans-serif
Arabic:     'Noto Sans Arabic', 'Geeza Pro', sans-serif
Cyrillic:   'Inter', system-ui, sans-serif
```

When you set `<html lang="ja">`, the CJK stack takes effect.

## RTL stance

**Supported.** Foundry's geometric sans and primary-block compositions translate cleanly to RTL.

What changes under `dir="rtl"`:
- Layout flips (Carbon handles via logical properties — `padding-inline-start` etc.)
- Directional icons mirror — chevrons, arrows, breadcrumb separators, undo/redo
- Display weight drops one step — Arabic glyphs read denser; `bold` becomes `medium`

What does NOT mirror:
- Logos, brand marks, illustrations
- Charts and data visualizations (axis labels reposition; data orientation stays)
- Code blocks (always LTR regardless of document direction)
- Numerals (use locale-appropriate; default to Western Arabic numerals)

## Layout gotchas

- **German is long.** Reserve 30% extra width for action buttons. "Speichern" fits where "Save" did; "Abbrechen" does not.
- **Japanese has no spaces.** Word-break should be `keep-all` for Japanese to avoid mid-word breaks.
- **Arabic line-height.** Bump line-height +0.1 to accommodate descenders.

## For LLMs

When generating RTL-aware code in Foundry:
1. Use logical CSS properties: `margin-inline-start` not `margin-left`
2. For directional icons, wrap in `<span class="rtl-mirror">` so a global `[dir="rtl"] .rtl-mirror { transform: scaleX(-1); }` rule handles them
3. Don't translate UI text speculatively — leave English placeholders with `// i18n:` comments
4. When rendering a Foundry button in Arabic, set font-weight one step lighter than the Latin equivalent
