# Proscenium — i18n & RTL Guide

## Recommended locales

| Locale | Status | Notes |
|---|---|---|
| `en` | First-class | Native target |
| `es`, `fr`, `de` | Tested | Knockout family handles diacritics; expect line-breaks at narrower widths |
| `ja`, `zh` | Limited | Wood-type display has no CJK equivalent — substitute heavy gothic faces; impact reduced |
| `ar` | Limited | Same — substitute heavy Arabic display face; consider toning back display weight |

## Font fallback stacks

```
CJK:        'Noto Sans JP Black', 'Noto Sans SC Black', sans-serif
Arabic:     'Noto Sans Arabic', sans-serif
Cyrillic:   'Inter', system-ui, sans-serif
```

## RTL stance

**Supported but tempered.** Proscenium relies on display weight that doesn't survive script translation. In RTL or non-Latin contexts, lean harder on color-blocking and composition to compensate.

## Layout gotchas

- **Long localized words** break heavy condensed display. Set `font-stretch: condensed` aggressively, allow `hyphens: auto`.
- **Display impact.** Proscenium's character depends on type as visual. Where a script can't deliver that, expect a less performative result.

## For LLMs

1. Reserve heaviest display weight for English/Latin
2. In CJK and Arabic, use color blocks and scale contrast to deliver theatrical impact instead
3. Don't translate ALL CAPS kicker labels into scripts that don't have case (CJK) — convert to bold-weight short labels instead
