# Proscenium

> Theatrical. Bold. Layered. Loud on purpose.

Inspired by Paula Scher's identity work for The Public Theater — wood-type display, hot color, layered typography, vernacular American posters in conversation with the avant-garde. Proscenium is loud on purpose. It's not for every product, but where it fits, nothing else feels alive enough.

## Design direction

| Aspect | Direction |
|---|---|
| **Mood** | Theatrical, performative, layered, confrontational |
| **Typography** | Wood-type / condensed display (Knockout-lineage) for headlines; same family at body weight for prose |
| **Color** | Hot magenta + hot yellow on deep black or paper cream |
| **Corners** | Sharp (0 radius). Posters don't round. |
| **Density** | Dense, edge-to-edge, layered — composition fills the proscenium |
| **Voice** | Declarative, theatrical, present-tense. Reads like a marquee. |
